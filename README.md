## 我做什么

帮支付相关商户把**合规与申诉**跑通：材料理解、对话辅助、工单与运营后台，并接到微信 / 支付宝官方支付与多域名 OAuth。

同一套工程能力也会落到**微信小程序**（知识付费、导航聚合）和**小游戏 / 互动产品**（联机体素、打地鼠、Canvas 玩法）。

> 原则：生产环境优先；商业系统源码私有；可复用工具与玩法开源。
