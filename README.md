<h1 align="center">艾阳 · 软件开发与商家数字化</h1>

<p align="center">给商家和中小团队做线上经营工具、内部系统与持续维护</p>

## 做什么

面向商家与中小团队的软件外包与技术支持：把线下的经营流程搬到线上，接好支付、接口和部署，交付后继续维护。

## 业务方向

**软件开发与系统集成**
按业务流程做小程序、Web 系统与后台管理，接入支付、消息、第三方平台接口，输出可运行、可交接的代码。

**电商技术支持与 IT 运维**
商城与店铺系统的搭建、迁移与故障处理，服务器部署、域名与证书、日常巡检。

**商户材料整理协助**
协助整理商户申诉、资质与运营材料，把散落的凭证归成可提交的结构化文档。
